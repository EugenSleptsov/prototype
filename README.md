# PROTO // TYPE

Игра об эволюции «снизу вверх»: от элементарных частиц к жизни. Концепция — в [DESIGN.md](DESIGN.md).

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8765
```

## Значки жестов

Мышь (вести, клик, зажать, отпустить, колесо) и клавиша с любой надписью рисуются из `js/gestures.js` — на заставке они стоят в строке управления. Готовые файлы для подсказок и соцсетей лежат в `gestures/*.svg`; пересобрать их из того же кода:

```bash
node tools/gestures.mjs
```

## Тесты

Без зависимостей и сборки — встроенный `node:test` (Node 22+):

```bash
npm test
```

`tests/harness.mjs` грузит все скрипты из `index.html` в один `vm`-контекст (как классические `<script>` в браузере), DOM и canvas — заглушки, `Math.random` — с зерном. Что проверяется:

- `methods.test.mjs` — каждый `this.метод()` в файле существует (ловит стёртые методы на редких путях, как `genFirst`);
- `particles.test.mjs` — пустота, созданный свет, ступени удара и ⚡, матрица рождения до и после Хиггса, три струи, обучение, рецепт в задании (поколения II–III — наполовину, целиком после двух промахов), регрессии;
- `sling.test.mjs` — карта на уровнях с рогаткой (WASD, тяга по пустому месту), длина резинки и мягкий бросок;
- `world.test.mjs` — мир без края (ядра, звёзды, атомы, молекулы): вдали от старта вокруг снова Вселенная, новое приходит из-за края кадра, чужое вдали растворяется, своё — нет; переходы берут твои же тела на тех же местах, смена масштаба (звезда, ×5 у молекул) — без скачка на экране;
- `roles.test.mjs` — роль семейства у «Рождения X»: e⁺e⁻ притягиваются и гаснут в γγ (✦, на виду ещё ⚡; пара, родившая Z, — не вспышка), запас u/d растёт по таймеру поровну и в эпохе 4 ложится готовыми тройками, снятый распад c s b μ τ платит ✦ и не стоит ⚡, t Вселенной в кадре заряжает ⚡ до полного (твой t — нет, с перезарядкой), роль видна в подсказке кнопки лавки;
- `regress.test.mjs` — регрессии из ревью: «Звёздный синтез» не ест собранные к сверхновой ¹²C, рогатка после «Синтеза» варит «Первичный бульон», лавка частиц не отрезает пункт «для задания», ×4 ускоряет всю игру уровня частиц, забег с выбранного на заставке уровня запускается и играется;
- `uni.test.mjs` — «Законы Вселенной»: каждый закон («Сформировать закон») — строка в сводке справа, ровный доход ✦/мин капает в ✦ уровня, лавка показывает, сколько ✦/мин принесёт покупка, каждое следующее «Рождение X» дороже на 20 %, в эпоху 4 частиц рождения стоят, в итогах уровня — «✦ от Вселенной», новый уровень — с чистой сводки;
- `fly.test.mjs` — копилка: «+N ✦» в мире — искры летят к счётчику «знания», он показывает баланс без того, что в полёте, и догоняет его; без счётчика на экране и без ✦ в надписи ничего не летит, новый уровень — без чужих искр;
- `teach.test.mjs` — учит действием: пустой клик и клик по знакомому свету не тратят ⚡, важное родилось впервые в жизни (глюон третьей струи) — стоп-кадр со стрелкой, один раз за забег и не для знакомого, жест «зажми у двух» не вышел — подсказка с жестом и курсор-подсказка сразу, тексты законов — без «без тебя»; у подсказок — показ, а не только текст: значки жеста (в раскачке — в такт шарику), стрелка к кнопке лавки, когда хватает на закон;
- `play.test.mjs` — играбельность: рогатка бросает в 1,75 раза быстрее (пороги ядер — вместе с ней) и с отдачей; двойной клик по связи рвёт молекулу и не берёт тело; Вселенная 8 с не трогает то, что ты брал, и сводит пары реже; остаток ✦ ÷ 10 уходит на следующий уровень (без очков, строкой в итогах и искрами при входе); электроны садятся на ионы только заторможенными (ждать бесполезно), след тормозит и рядом; «связал — разорвал — связал» не даёт очков; два ⁴He в ядре звезды сами сливаются в ⁸Be при новом барьере;
- `logic.test.mjs` — баги логики из аудита: ⁴He + ⁴He в «Ядрах» — не реакция (без «нового» гелия и ✦, автоматика её не выбирает), ⁷Li + p — по-прежнему; доля нейтральных в «Атомах» — по ионам у кадра; финал «Молекул» — с итогами уровня и ✦ последнего кадра в очках; ручной поворот Q / E при прицеливании не перебивается; щипок без тела в руке не отменяет следующий бросок;
- `cine.test.mjs` — кадр-пауза важного знания: открытие впервые в жизни, первый закон, закон глюонов (с жестом и схемами g + γ и g + g) и начало уровня (с путём Вселенной и «зачем») останавливают время на ленте поперёк экрана, карточка открытия глюона говорит, что дальше — его закон, знакомое из прошлых забегов — без паузы, несколько открытий — по очереди, клик в первые 0,6 с не смахивает;
- `smoke.test.mjs` — бот беспорядочно играет все 4 эпохи частиц (мышь и сенсор) и все этапы лестницы с отрисовкой и HUD: любое исключение — падение.

На каждый пуш типы и тесты гоняет GitHub Actions (`.github/workflows/test.yml`). Меняешь игру — добавь тест рядом.

## Типы

Игра остаётся на JS без сборки, а TypeScript только проверяет её (`tsc --noEmit`, единственная зависимость — `typescript` для разработки):

```bash
npm install
npm run typecheck   # или npm run check — типы и тесты
```

Проверка строгая (`strict`) и включается по файлу строкой `// @ts-check` в начале — сейчас это `js/core.js` и `js/s_particles.js`. Чтобы файл прошёл:

- состояние этапа объявлено в `types/game.d.ts` (`ParticlesState`, объект мира `Q`, `Focus`, `Track`…) и «распаковано» в начале объекта этапа (`...(/** @type {ParticlesState} */ ({}))`) — tsc знает каждое поле `this.…` и ловит опечатки и стёртые методы;
- у методов — однострочный JSDoc: `/** @param {Q} a @param {Q} b @param {boolean} [spont] */`;
- там, где правильность держится на предусловии, которого tsc не видит (обучение идёт, у глюона есть антицвет), стоит явное приведение `/** @type {Tut} */ (this.tut)` с пояснением.

- договор этапа с `main.js` — интерфейс `Stage` (`G.stage` и `G.prev` — этого типа); строка `/** @typedef {IsStage<typeof Particles>} … */` в конце файла этапа даёт ошибку, если этап его не выполняет (нет `bg`, `tally()` вернул не то);
- элементы страницы — через `byId('…')` (util.js): элемента нет — ошибка сразу, а не `null` дальше.

Новое поле состояния — сначала в `types/game.d.ts`, потом в `enter()`. Следующий файл переводится так же: `// @ts-check` → `npm run typecheck` → объявить поля и параметры.

## Ветки

- `main` — текущая разработка (v2: уровень частиц в начале, дальше этапы v1).
- `release/<версия>` — замороженный снимок каждого крупного релиза, чтобы можно было вернуться.
  В релизные ветки после создания не коммитим.

| Ветка | Что внутри |
|---|---|
| `release/v1-stages` | Линейный прототип: кварки → ядра → атомы → молекулы, своя физика на каждом этапе. Старый прототип «ешь меньшее» лежит в `legacy/proto-v0.html` |

Вернуться к релизу:

```bash
git switch release/v1-stages
```
