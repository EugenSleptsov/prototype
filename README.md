# PROTO // TYPE

Игра об эволюции «снизу вверх»: от элементарных частиц к жизни. Концепция — в [DESIGN.md](DESIGN.md).

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8765
```

## Тесты

Без зависимостей и сборки — встроенный `node:test` (Node 22+):

```bash
npm test
```

`tests/harness.mjs` грузит все скрипты из `index.html` в один `vm`-контекст (как классические `<script>` в браузере), DOM и canvas — заглушки, `Math.random` — с зерном. Что проверяется:

- `methods.test.mjs` — каждый `this.метод()` в файле существует (ловит стёртые методы на редких путях, как `genFirst`);
- `particles.test.mjs` — пустота, созданный свет, ступени удара и ⚡, матрица рождения до и после Хиггса, три струи, обучение, регрессии;
- `smoke.test.mjs` — бот беспорядочно играет все 4 эпохи частиц (мышь и сенсор) и все этапы лестницы с отрисовкой и HUD: любое исключение — падение.

На каждый пуш тесты гоняет GitHub Actions (`.github/workflows/test.yml`). Меняешь игру — добавь тест рядом.

## Ветки

- `main` — текущая разработка (v2: уровень частиц в начале, дальше этапы v1).
- `release/<версия>` — замороженный снимок каждого крупного релиза, чтобы можно было вернуться.
  В релизные ветки после создания не коммитим.

| Ветка | Что внутри |
|---|---|
| `release/v1-stages` | Линейный прототип: кварки → ядра → атомы → молекулы, своя физика на каждом этапе. Старый прототип «ешь меньшее» лежит в `legacy/proto-v0.html` |

Вернуться к релизу:

```bash
git switch release/v1-stages
```
