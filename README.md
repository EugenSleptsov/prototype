# PROTO // TYPE

Игра об эволюции «снизу вверх»: от элементарных частиц к жизни. Концепция — в [DESIGN.md](DESIGN.md).

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8765
```

## Значки жестов

Мышь (вести, клик, зажать, отпустить, колесо) и клавиша с любой надписью рисуются из `js/gestures.js` — на заставке они стоят в строке управления. Готовые файлы для подсказок и соцсетей лежат в `gestures/*.svg`; пересобрать их из того же кода:

```bash
node tools/gestures.mjs
```

## Тесты

Без зависимостей и сборки — встроенный `node:test` (Node 22+):

```bash
npm test
```

## Типы

Игра остаётся на JS без сборки, а TypeScript только проверяет её (`tsc --noEmit`, единственная зависимость — `typescript` для разработки):

```bash
npm install
npm run typecheck   # или npm run check — типы и тесты
```

Проверка строгая (`strict`) и включается по файлу строкой `// @ts-check` в начале — сейчас это `js/core.js` и `js/s_particles.js`. Чтобы файл прошёл:

- состояние этапа объявлено в `types/game.d.ts` (`ParticlesState`, объект мира `Q`, `Focus`, `Track`…) и «распаковано» в начале объекта этапа (`...(/** @type {ParticlesState} */ ({}))`) — tsc знает каждое поле `this.…` и ловит опечатки и стёртые методы;
- у методов — однострочный JSDoc: `/** @param {Q} a @param {Q} b @param {boolean} [spont] */`;
- там, где правильность держится на предусловии, которого tsc не видит (обучение идёт, у глюона есть антицвет), стоит явное приведение `/** @type {Tut} */ (this.tut)` с пояснением.

- договор этапа с `main.js` — интерфейс `Stage` (`G.stage` и `G.prev` — этого типа); строка `/** @typedef {IsStage<typeof Particles>} … */` в конце файла этапа даёт ошибку, если этап его не выполняет (нет `bg`, `tally()` вернул не то);
- элементы страницы — через `byId('…')` (util.js): элемента нет — ошибка сразу, а не `null` дальше.

Новое поле состояния — сначала в `types/game.d.ts`, потом в `enter()`. Следующий файл переводится так же: `// @ts-check` → `npm run typecheck` → объявить поля и параметры.

## Ветки

- `main` — текущая разработка (v2: уровень частиц в начале, дальше этапы v1).
- `release/<версия>` — замороженный снимок каждого крупного релиза, чтобы можно было вернуться.
  В релизные ветки после создания не коммитим.

| Ветка | Что внутри |
|---|---|
| `release/v1-stages` | Линейный прототип: кварки → ядра → атомы → молекулы, своя физика на каждом этапе. Старый прототип «ешь меньшее» лежит в `legacy/proto-v0.html` |

Вернуться к релизу:

```bash
git switch release/v1-stages
```
